# pydseams branding

Original mark for **pydseams** (Python Frame API on the d-SEAMS
engine). Same hexagonal ice cage as `dSeamsLogo.png`, drawn as
geometry, not a raster mashup.

## Concept

- **Hexagonal prism** — the d-SEAMS cage (HC / ice nanotube).
- **Amber frame** — the public type is `Frame`. Not the Python snake.
- **Cyan bonds, pale oxygens** — the engine palette (`#0D47A1`,
  `#81D4FA`, `#E3F2FD`) plus frame gold (`#F9A825`).
