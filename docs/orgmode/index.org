#+begin_export rst
========
pydseams
========

Python bindings for the d-SEAMS C++ engine.
#+end_export

* Overview

~pydseams~ is the Python package. The compiled module is ~yoda~.
Helpers (~Frame~, ~read~, ASE, solvis) sit on that surface, the way
metatomic sits on its C API. ~import pydseamslib~ still works.

The engine and ~seams~ CLI live in
[[https://github.com/d-SEAMS/seams-core][seams-core]]. Lua is
~dseams~ in [[https://github.com/d-SEAMS/yodaStruct][yodaStruct]].

#+begin_src python
import pydseams as ds

frame = ds.read("water.lammpstrj")
print(frame.chill_plus())
print(frame.cages())
#+end_src
