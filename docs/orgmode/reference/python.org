Catalog of the live Python names. Autodoc of the helpers and of
~yoda~ is on the [[file:../api.md][API]] page.

* Install

| extra | provides |
|-------+----------|
| ~pip install pydseams~ | ~Frame~, ~read~, ~yoda~ |
| ~pip install 'pydseams[ase]'~ | ~from_ase~, ~Frame.to_ase~ |
| ~pip install 'pydseams[solvis]'~ | ~to_solvis~ (pulls ASE) |

Nix, from a checkout: ~nix build~ (package ~pydseams~), ~nix develop~.

Requires Python 3.12+. Wheels are the CPython 3.12 limited ABI.

~import pydseamslib~ re-exports ~pydseams~.

* Loaders

| name | role |
|------+------|
| ~pydseams.read(path, frame=1, **kwargs)~ | suffix-dispatching loader |
| ~pydseams.Frame(...)~ | one-frame handle (LAMMPS dump by default) |
| ~Frame.from_file~ | LAMMPS dump; guesses type 2 then type 1 |
| ~pydseams.from_ase~ / ~Frame.from_ase~ | ASE ~Atoms~; ~select="O"~ |
| ~pydseams.from_arrays~ / ~Frame.from_arrays~ | ~(N, 3)~ positions and three box lengths |
| ~pydseams.from_xyz~ / ~Frame.from_xyz~ | XYZ via ~yoda.readXYZ~ |
| ~pydseams.from_chemfiles~ / ~Frame.from_chemfiles~ | PDB / GRO / DCD when chemfiles is linked |
| ~pydseams.from_con~ / ~Frame.from_con~ | eOn ~.con~ when readcon-core is linked |
| ~pydseams.available_readers()~ | which optional C++ readers this build linked |

~read~ suffix table:

| suffix | constructor |
|--------+-------------|
| ~.xyz~ | ~Frame.from_xyz~ |
| ~.con~ | ~Frame.from_con~ |
| ~.pdb~, ~.gro~, ~.dcd~ | ~Frame.from_chemfiles~ |
| ~.lammpstrj~, ~.dump~, ~.lammps~, other | ~Frame.from_file~ |

Common kwargs: ~frame~ (1-indexed), ~cutoff~ (Angstroms, default 3.5),
~bonded~ (~"auto"~, ~"hbond"~, ~"cutoff"~), ~atom_type~, ~region~.
~bonded="auto"~ uses hydrogen bonds when hydrogens are available.

* Frame

| name | role |
|------+------|
| ~n_atoms~, ~box~, ~positions~ | geometry |
| ~chill_plus~ / ~chill~ | four-neighbour ice labels; no files written |
| ~classify_chill_plus~ / ~classify_chill~ | aliases of the above |
| ~cages(seeded=True, k=4)~ | HC / DDC membership |
| ~to_ase~ | ASE ~Atoms~; needs ~pydseams[ase]~ |
| ~to_solvis~ | solvis ~System~; needs ~pydseams[solvis]~ |
| ~load_frame(n)~ | next frame of a trajectory file |
| ~neighbor_list~, ~hbonds~, ~rings~ | graphs used by the classifiers |

~from_ase(atoms, select="O", cutoff=3.5, bonded="auto")~: ~select~ is
a symbol, an atomic number, or ~None~. The cell must be orthorhombic.

* Return types

| name | role |
|------+------|
| ~IceCounts~ | CHILL / CHILL+ histogram (~counts.cubic~, ~counts["hexagonal"]~) |
| ~CageScore~ | per-atom HC / DDC flags; ~n_ih~, ~n_ic~, ~n_water~ |

~to_ase~ writes ~arrays["ice_type"]~ after CHILL and ~arrays["hc"]~ /
~arrays["ddc"]~ after ~cages()~.

* Compiled module

~pydseams.yoda~ is the nanobind extension. Call it for the raw
engine (~PointCloudDouble~, ~readLammpsTrjreduced~, ~neighListO~,
...). New application code uses ~Frame~ / ~read~ / ~from_ase~.
