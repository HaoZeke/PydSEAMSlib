#+TITLE: API reference
#+OPTIONS: toc:nil num:nil

The public Python surface is ~Frame~, ~read~, and the ASE helpers.
Autodoc of those helpers is the Sphinx landing
[[file:../../source/api.md][api.md]] (~automodule~ + Napoleon).
~pydseams.yoda~ is mocked in the Sphinx build, so the tables below
are the hand list of functions ~Frame~ and the I/O helpers call,
taken from ~src/bindings.cpp~.

* Package constructors

| name | role |
|------+------|
| ~pydseams.read~ | suffix-dispatching loader |
| ~pydseams.from_ase~ | ASE ~Atoms~ to ~Frame~ |
| ~pydseams.from_arrays~ | ~(N, 3)~ positions and three box lengths |
| ~pydseams.from_chemfiles~ | PDB / GRO / DCD when chemfiles is linked |
| ~pydseams.from_con~ | eOn ~.con~ when readcon-core is linked |
| ~pydseams.from_xyz~ | XYZ through ~yoda.readXYZ~ |
| ~pydseams.available_readers~ | which compiled readers this build linked |
| ~pydseams.to_solvis~ | optional ~solvis.System~ view |

36 symbols. Names match ~src/bindings.cpp~; do not invent extras.
